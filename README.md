# Target Corporation Three-Statement Financial Model

An Excel model connecting Target Corporation's income statement, balance sheet, and cash flow statement. It uses FY2023–FY2025 historical results and projects FY2026–FY2028 using stated assumptions.

## What's in the workbook

- **Historical:** Financial results from Target's annual report
- **Assumptions:** Inputs used for the forecast
- **Schedules:** Supporting calculations
- **Three Statements:** Linked financial statements and forecasts
- **Checks:** Balance sheet and model checks
- **Summary:** Key results and a free cash flow chart

## Method

I entered historical figures, calculated forecast drivers, linked the three statements, and checked that the projected balance sheets balance. Forecast figures are estimates for a portfolio project, not Target's guidance.
